# 核算摘要与合同批量导出

## 成本统计摘要

- 仅重新设计成本统计查询后的结果区域；查询条件、商品成本填写页与手机页保持原样。
- 一体化白色核算概览，三个金额指标以分隔线组织，不再嵌套多个彩色卡片。订单数量和商品数量以大字号显示在右侧轻量数量区，窄桌面下移到金额区下方。
- 金额增加千分位，直接格式化服务端十进制字符串，不重新计算、不转浮点、不改变精度；缺失金额仍为待补全，0 仍为明确零值。
- 保留缺失成本提示及款号问号提示、核算期间、汇率、生成时间；完整成本、待补全与负毛利有独立展示状态。
- 核算明细区增加独立标题、汇总口径和结果数，款号、尺码、数值列与分页样式统一，原订单展开明细及导出逻辑保留。
- 仅调整展示，不改变成本匹配、历史核算、查询/导出数据或币种规则。

## 合同创建年月筛选

- 合同列表使用「创建月份」筛选，例如 `2026-11`；不是交货日期筛选。
- 桌面筛选栏的搜索框、月份选择与查询/重置按钮统一为 32px 高度、10px 间距，顶部与底部对齐。
- 月份按北京时间计算，含本月第一天 00:00，不含下月第一天 00:00。
- 月份可清空，清空后查看全部月份；与原合同编号、工厂、款号及 SKU 关键字条件共同生效。
- 查询条件及分页继续保存在 URL 中。改变关键字或创建月份后清空原勾选，翻页保留勾选。
- 桌面列表高度随窗口调整，合同明细在表格内部上下滚动，表头、筛选与分页保持可见，不再随合同数量把整页撑长；手机卡片布局保持原样。

## 批量导出 Excel

合同管理右上角「批量导出」提供两个范围：

1. **导出勾选合同**：支持跨页勾选，只导出当前筛选范围内所选合同。
2. **导出筛选全部**：导出所有符合已查询条件的合同，不限当前分页。

每次下载一个 `.xlsx` 文件，每份合同使用独立工作表，沿用原单合同 Excel 的数量、尺码、图片、附件与打印模板。工作表名根据合同号生成，自动处理 Excel 不支持的字符、31 字符限制及重名。原单份合同导出入口保持不变。

批量接口：`GET /api/admin/contracts/export?keyword=...&createdMonth=YYYY-MM&contractIds=1,2`。

- `contractIds` 未传时导出筛选全部，传入时只导出所选合同；空选择不等同于全部。
- 复用现有导出排队、并发限制、资源阶段与工作进程超时；下载失败后保留现有页面错误提示。
- 复用原合同查看/导出权限，不增加账号权限。
- 使用已保存合同快照，生成结束前复核账号及合同版本；合同被修改或移除时提示重新导出。
- 导出不创建合同、不更新库存、不生成订单或仓库打单标记。
