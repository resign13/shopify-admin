# 共用合同未送余额与到货超收

- 颜色 SKU（商品 ID）＋真实尺码共用一份实际未送余额。建合同加采购数量，修改合同只加减新旧差额，手工录入修改后的余额。合同交期、甲乙方、图片等选填资料不参与库存计算。
- 取消合同须确认每个尺码本次冲减；默认 0，仅作废单据。冲减不得超过对应合同数量或实际未送；余额变化时重新确认。待验货、合格和现货不动。仍被有效合同实际订购的商品/尺码不得删除。
- 单次新到货以事务锁定的实际未送余额为基数，超收上限为 `floor(余额 × 15 / 100)`。余额 100 时可收 115，不可收 116；分次收货按下一笔的余额重新计算，余额 0 不结转额度。历史超收只作审计，不参与计算或阻止合同数量修改。
- 默认先扣未送，实际超出的部分标记为超收。同尺码已加入新合同而旧批多做时，可以选填本次超收，只扣普通数量。例如余额 200、到货 110、超收 10，未送剩 100。
- 超收标记随待验货和合格阶段转移，普通数量优先转合格、超收优先打回。打回只把原来扣过未送的普通部分返还。例如未送 100 → 登记 115 → 全部打回，未送恢复 100，现货不变。普通入库清合格及其超收标记；临时入库独立。
- Excel v7 可选填本次超收；v1–v6 可继续导入。预览和确认以同一套规则处理原始填写意图，只改现货时不检查无关阶段旧值。
- 迁移仅允许交期列为空，保留既有库存、合同及台账。旧合同归属字段留作历史，不再影响库存。新版开始接收统一规则的登记或保存无交期单据后，故障修复应继续使用能读取这些记录的新版代码，不以旧规则处理新记录。
