# 项目稳定性升级（2026-10-22，本地验收）

## 状态与边界

两仓库分支：`feature/project-stability-upgrade`。本轮为本地开发与验收，未提交 PR、未发布、未重启生产服务。SSH 配置、凭证、每日只读同步及生产业务数据保持原状。本次没有数据库结构迁移。

既有私有附件切换、登录保护 6.4 的生产暂缓决定保持不变；现有实现参与回归，但本轮不擅自启用。源码改造不等于已经在生产生效。

## 已完成

### 导出与资源
- 订单 Excel、PI、合同导出先取得短事务数据快照，图片读取和工作簿生成在业务事务之外执行。完成后短事务重新核验当前会话、业务权限和记录版本；订单变动返回冲突，仓库打单记录只在最终核验通过时更新。
- 图片改用请求级临时磁盘缓存，限制抓图并发为 2；移除旧的 128 张/32 MiB 批次截断，历史订单附件不再按上传入口数量上限截断。上传数量限制不变。
- 临时文件随请求释放。图片来源校验、TLS 校验和超时继续沿用现有实现；失败图片仍按现有缺失提示处理。
- 服务端导出增加跨账号、跨进程、跨两端共享并发预算，默认 1。数据库协调连接在导出期间保留，业务事务不再覆盖图片网络等待。
- Gunicorn 默认改为每端 2 个 worker、每 worker 2 线程。显式配置的 worker 数仍优先，不自动改生产环境变量。

### 查询及页面
- 财务汇总由 PostgreSQL 聚合；页面只读取当前分组的明细，Excel 仍读取完整结果。首次成本补算、后续时间节点、运费排除和缺失成本规则不变。
- 商品管理可筛选启用、停用、全部商品；财务标出整款停用状态，可按精确款号跳转商品管理。不会删除历史成本或自动清理停用商品。
- 商城订单中心使用服务端分页与状态/时间筛选，详情按指定订单查询。旧无分页参数调用保留原完整响应。
- 库存页读取完整的精简库存数据，减少图库、描述等无关字段；不截断 SKU 或真实尺码。关联商品先在数据库限制数量再装配详情。
- 商城路由按需加载。网络失败保留已显示订单并提供重试，过期请求不覆盖新结果；历史附件完整展示。
- 商品列表为主要信息列保留可读宽度，窄屏使用表格内滚动，不挤成单字列。

### 发布、监测与维护
- CI 验证构建后保存前端产物，部署复用同一次工作流的已验证产物，不重复构建。
- 发布控制器支持纯前端版本切换：后端文件清单、正在运行的后端和已加载环境均一致才不重启；否则继续原有停启流程。备份、发布许可、健康检查和兼容回滚保留。
- 此模式依赖现有 Nginx 从 current/frontend/dist 提供页面、公共静态资源目录保留旧资源。不得删除仍被 /proc/MainPID/cwd 使用的旧 release。直接访问开发 Flask 静态页面不作为生产静态切换验收依据。
- 每个响应有 X-Request-ID；日志记录注册路由、状态、耗时，每 worker 约 60 秒采样连接池和 Linux RSS。导出记录快照/生成/完成等实际埋点阶段。日志不写请求参数、正文或凭证。
- 新增离线日志汇总脚本，输出接口 P50/P95/max、状态计数、导出阶段、连接池及观测到的 worker RSS。
- 明确 17 个两仓库共享模块边界并提供一致性检查，渠道权限与业务逻辑不盲目合并。更新已过时的架构/会话/发布说明。

## 配置

| 配置 | 本轮默认 | 说明 |
|---|---:|---|
| GUNICORN_WORKERS | 2 | 每端；现有显式环境变量优先 |
| threads | 2 | 每 worker，保持原值 |
| SECURITY_EXPORT_GLOBAL_CONCURRENT | 1 | 可设 1–4，两端必须一致 |
| 每账号导出频率 | 原配置 | 未放宽 |
| 外部 API 额度 | 原配置 | 每 Key 60/min、IP 300/min、全局 10/s、在途 4/Key 2 未调整 |

全局导出额度不足返回 429，Retry-After 为 5 秒。商城浏览器本地生成的库存 PDF 不占用服务端工作簿并发槽，其查询仍使用既有额度。

连接池不因本轮修改扩大。上线时应核对进程数 × 各池上限及管理/迁移连接余量；不要仅依据空闲内存增加 worker 或并发。新日志为实际负载调整提供依据，不代表已经完成生产容量测试。
