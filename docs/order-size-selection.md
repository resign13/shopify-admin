# 订单选品：独立尺码数量

## 页面与边界

- 订单选品每个颜色 SKU 一行，仅展示自身配置的真实尺码；标签在数量框上方，多尺码自动换行。
- 不展示标题、图片、单价、总件数和库存；桌面、平板和手机不产生尺码横向滚动。
- 使用 `sizePrices` 数组的配置顺序。数字尺码也不通过 `Object.keys` 排序，`S`、`28`、`S/28` 是不同标识。
- `ProductPicker` 的订单数量模式交给 `OrderQuantityPicker`；默认商品选择模式不变；订单商品明细也按每 SKU 独立尺码换行，保留库存差额预览、总件数及移除。

## 状态与应用

- 打开时从订单页面读取数量；搜索、分类和分页不清空本次暂存。
- 输入变更自动进入待处理；查看待处理时，输入暂时清空不移除正在编辑的商品行。
- 行内只保留“加入”，新旧 SKU 使用同一入口，操作后保持弹窗打开并重建基线，避免重复加入。
- “完成”只同步已在订单页面中的 SKU 数量并关闭。尚未点击“加入”的新 SKU 不自动加入；存在此类填写时先提示是否放弃，取消则保留所有输入。无变更也可直接完成。
- 已有商品覆盖数量，明确归零允许应用；确认弹窗列出数量前后变化。旧成交价及报价元数据保留。
- 应用前按 ID 批量读取当前商品，任一商品或尺码失效、数量不合法或超出 500 个有效尺码行时，整个批次不修改订单页面。
- 新加入尺码使用当前目录报价；参考价变化须确认。新商品全尺码为 0 时也可明确点击“加入”，生成一个零数量页面占位行，主页面可继续填写任意真实尺码；正式提交过滤零数量，保存草稿可保留占位行。
- `applyQuantities` 回调只更新页面商品缓存和商品行，不创建订单、不扣库存。正式保存、草稿及返单沿用既有接口。
- 关闭、遮罩、Esc、刷新和路由离开保护未应用数量；不额外持久化选品暂存。
